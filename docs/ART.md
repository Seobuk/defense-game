> 사용자 기준: **"어설프면 안 돼. 진짜 상용게임처럼 보여야 됨."** · 마법 판타지 방향: **"너무 단순해"** (DESIGN.md 맨 위)
> 이 문서는 모든 화면·스프라이트·UI·이펙트의 **단일 기준**이다. 새로 그리는 것은 전부 여기에 맞추고, 기존 것은 우선순위(§13)대로 고친다.
> 파일 에셋은 **번들 글꼴(woff2)과 UI 아이콘(SVG)** 만 쓴다. 캐릭터·배경·이펙트는 전부 코드(캔버스 경로 → 오프스크린 캐시)로 그린다.
> 코드 구조와 담당은 §14(모듈 계약 · 파일 소유). 오프라인 APK라 외부 CDN·원격 글꼴 금지.

## 0. 방향 한 줄 — **"반짝 성채 (Bright Keep)"**

두툼한 치비 판타지. **굵고 어두운 외곽선 + 3단 셀 셰이딩 + 좌상단 림라이트**, 채도 높은 캐릭터가 한 톤 낮은 배경 위에서 튀어나온다. 마법은 **빛(가산 글로우) + 룬 마법진 + 마력 입자**로 화면을 채운다. UI는 **광택 있는 젤리 버튼 + 베벨 프레임 + 테두리 글자(stroke) + 딱 끊긴 그라데이션 숫자**. 참고 감각: 탑 그로싱 캐주얼/방치형(궁수의 전설·서바이버류·클래시류)의 "장난감 같은 입체감"과 킹덤 러시류 영웅의 존재감.

세 가지 원칙:
1. **읽힘이 먼저** — 적·탄·보상은 배경에서 항상 분리되어 보여야 한다(명도 대비 + 외곽선 + 림). 캔버스 HUD·DOM HUD가 보스를 가리면 실패.
2. **모든 것은 같은 손으로 그린다** — 외곽선 색·두께, 빛 방향(좌상단), 모서리 둥글기, 글꼴·숫자 스타일이 화면마다 달라지면 안 된다. 이모지 금지.
3. **모든 입력에 즉각 반응** — 누르면 눌리고(80ms 안), 놓으면 튀어 오르고(오버슈트), 보상은 반드시 날아가 꽂힌다.

| 보스 (r 52~80) | 6~7 | 3.5 |
| 영웅 · 성벽 마법사 | 5 | 2.5 |
| 소환수(드래곤·골렘·망령) | 4.5 | 2.5 |
| 마법탄 헤드·코인·드롭 아이템 | 2.5 (탄은 외곽선 대신 어두운 에지 헤일로) | — |
| 배경 소품 | **없음 또는 1.5** (선을 약하게 → 캐릭터와 층 분리) | — |

`lineWidth`는 r 비율이 아니라 위 고정값(굽는 해상도와 무관한 월드 단위). 외곽선은 채움 **뒤에**, `lineJoin/lineCap='round'`.

### 3.2 셀 셰이딩 레시피 (3톤 + 림 + 광택) — `core.cel()` 이 1~3을 한 번에
1. **base** 채움 → 2. **shade**: 같은 경로 `clip()` 후 (+0.25r, +0.3r) 이동한 같은 모양을 shade 색(명도 −18%, 색상 `--ink` 쪽 10°)으로 → 우하단 초승달 → 3. **light**: 좌상단 0.5r 타원(명도 +15%) → 4. **rim light**: clip 안 좌상단 호 2~3px, 테마 키라이트(§2.2), 화산만 하단 → 5. **광택**: 흰 타원 1 + 점 1 (젤리·금속·보석만, `core.shine`) → 6. **외곽선** → 7. **접지 그림자** 타원 `rgba(34,22,58,.35)` 1.8r × 0.5r.
그라데이션은 광택용 방사형 1개까지. 흐릿한 그라데이션 여러 겹 금지.

### 3.3 실루엣·가독성
- **썸네일 테스트**: 32×32 검정 실루엣으로 줄여도 종류가 구분(귀·뿔·무기·방패 등 고유 돌출부 1개 이상).
- 치비 비율 머리:몸 = 1:1 ~ 1.2:1, 큰 눈(흰자 + 하이라이트 점).
- 적 종류마다 **대표 색 하나**(몸통 60% 이상), 같은 테마 적끼리 색상 45° 이상 차이. 배경과 같은 색상대(±20°)면 명도 25%↑ 차이 또는 림 두껍게.
- 엘리트: 같은 적 ×2.1 + 금 왕관/뿔 장식 + 발밑 붉은 링. 보스: 전용 실루엣 + 상시 약한 오라.
- 피격: 흰 번쩍임(`hitT`), 찌그러짐 x1.15/y0.88 → 120ms 오버슈트 복귀. 등장: 위 여분(topExtra)에서 걸어 들어올 때 0.2초 알파 페이드.
- **영웅 클래스 실루엣**: 기사 = 큰 방패 + 투구 깃, 궁수 = 긴 활 + 후드, 마법사 = 뾰족 모자 + 지팡이 오브, 성직자 = 후광 링 + 철퇴, 암살자 = 목도리 꼬리 + 쌍단검. 티어(견습→전설)는 어깨·망토·광택·오라로만 올린다(실루엣 유지).
- **성벽 마법사**: P1 = 붉은 로브·금 장식·화염 오브, P2 = 푸른 로브·흰 장식·냉기 오브. 강화 티어 0~4 = 망토 → 오라 → 룬 받침 → 큰 오브.

## 6. 데미지 숫자 규칙 (FX — 지금 가장 시끄러운 요소)
> **구현(폴리시 1차, `fx.js dmgNum/placeNum`)**: 대상(적 객체)별 0.15초 안 연타는 소유자와 무관하게 한 숫자로 굴린다(합칠 때 1.15 톡) · 동시 최대 8개(간소 5), 넘치면 가장 약하고 오래된 숫자부터 · 크기 = 등급(일반 .85/치명 1.2/큰 치명 1.6) × 최근 최대 피해 대비 √상대값 · 자리는 실제 글자 폭으로 재서 위/좌상/우상 칸 → 떠오르며 겹치면 서로 밀어냄 · 안전선 y ≥ hudY(158)(보스전 196), 영웅 버튼 영역 회피 · 치명만 '!' · 색: 나 금빛 흰색 / AI 청록 / 영웅 분홍 / 스킬 원소색 / 치명 주황 금 · **빨강 '−'는 받은 피해 전용**(성벽 체력판 옆, 영웅 머리 위).
- 크기 4단: 일반 **22**, 치명 **34**, 큰 피해(`big`) **46**, 보스 치명 최대 **56** 월드px. 그 이상 금지.
- 동시 표시 **최대 14개**(간소 6). 넘치면 가장 오래된 일반 숫자부터 제거.
- **합치기**: 같은 대상 + 같은 소유자(나/AI/영웅/스킬) + 0.12초 안 → 한 숫자로 합쳐 1.15 톡. 합쳐진 숫자는 더 센 등급 모양으로.
- **쌓기(겹침 금지)**: 새 숫자의 사각형이 기존 숫자와 겹치면 **위로 한 칸(글자 높이 ×0.9)씩 밀어 올린다**(최대 3칸, 넘으면 좌우 ±28 교대). 보스 위는 3개 **레인**(왼쪽·가운데·오른쪽)을 순환.
- **보스전**: 보스에 맞는 개별 일반 숫자는 끄고, 보스바 아래 **누적 피해 티커**(Impact 24, 0.5초마다 갱신, "+1.2M") + 치명·큰 피해만 개별 표시.
- 수명: 팝 인 90ms(0→1.25→1, back) → 위로 28px 400ms → 페이드 200ms. 치명은 좌우 흔들림 1회.
- 안전 영역: x 60~660, y ≥ `hudY(165)`(보스전엔 보스바 아래). 밖이면 안쪽으로 밀어 넣는다(잘리면 실패).
- 영웅·스킬 피해: 지금은 체력 감소로 추정(`fx.dmgScan`) → DoT·막타 누락. 정확히 하려면 sim `hit` 이벤트에 `o:2`(영웅)/`o:3`(스킬)·`kind`를 최소 추가(npm test 통과 유지).
- 설정 '간소' = 치명·큰 피해·누적 티커만.

## 9. VFX 규칙 (FX)

### 9.1 레이어 순서 (아래 → 위) — `render.js frame()`이 이 순서를 지킨다
배경(+위 여분) → 바닥 데칼·서리 결계 → 주변 입자 → 드래곤 경고 기둥 → 영웅 바닥(도발·이동 마커) → 궁극기 바닥 마법진 → 골렘 → **적**(그림자·오라·몸·표식·체력바) → 적 투사체 → 회오리 → 망령 → 얼음 창 → **마법탄** → 브레스 → 심판 예고 → **성벽** → 빛기둥 → 잔상 → **영웅** → **성벽 마법사** → 새끼 드래곤 → 파티클 → 팝 스프라이트(마법진·섬광) → 번개 → 운석 → 파이어볼 → 영웅 투사체 → 영혼 → 장비 드롭 → 동전 → **데미지 숫자** → LEVEL UP → 화면 틴트 → 캔버스 HUD(보스바·콤보·도장·팝업·배너·컷인) → 섬광 → (DOM HUD)

### 9.2 블룸·가산
- 빛은 **미리 구운 방사형 글로우**(`fx.gl(color)`)를 `'lighter'`로. 실시간 `shadowBlur`·`filter: blur` 금지.
- 글로우 한 프레임 최대 **60장**(넘치면 작은 것부터 생략), 파티클 ≤ 400.
- 발광 3층: 흰 코어(작게) + 원소 메인(중간, α .7) + 원소 에지 헤일로(크게, α .25).

### 9.3 타격 이펙트 표준
| 단계 | 시간 | 내용 |
|---|---|---|
| 섬광 | 0~60ms | 흰 코어 4각 별 0.6→1.3 |
| 버스트 | 0~140ms | 원소 색 링 확산 + 파편 5~8 |
| 잔여 | ~350ms | 원소별 잔여(연기·서리·불티) 감속 |
치명타: 섬광 ×1.6 + 60ms 히트스톱 + 대각 슬래시 1개. 처치: 팝콘(몸 색 조각 6~10) + 코인 분수.

### 9.4 원소 스킬 요지
- 화염: 파이어볼 = 꼬리 구체 → 버섯 폭발(주황 코어·검은 연기 링) + 그을음 1초.
- 번개: 지그재그 2겹(흰 2px + 노랑 6px + 보라 헤일로), 2프레임 번쩍, 낙뢰만 40ms 섬광.
- 냉기: 얼음 창 = 각진 결정 탄 + 서리 꼬리, 서리 결계 = 성벽 앞 육각 타일 띠 + 떠다니는 결정.
- 바람: 회오리 3겹 곡선 회전 + 휘말린 잎, 질풍 = 마법사 주위 민트 속도선.
- 신성: 심판 광선 = 기둥(흰 코어 + 금 헤일로) + 바닥 링, 수호의 빛 = 성벽 금빛 파동.
- 암흑: 저주 낙인 = 머리 위 보라 룬 + 연무, 영혼 수확 = 보라 영혼이 골드 HUD로 곡선 비행.
- 소환: 분홍 소환진 확산 → 소환수 **오버슈트 착지**.

### 9.5 화면 상태 틴트 (`fx.drawOverlays`)
광란 = 가장자리 가산 비네트(주황→자홍, 가장자리 25%) + 세로 속도선, **곱하기 틴트 금지** · 빙결 = 서리 프레임 + 시안 α.08 · 위기(성벽 30%↓) = 가장자리 빨강 맥동 1.2초 · 카드 선택 = `--night-900` 40% 딤 + 보라 비네트 + 회전 마법진. 전부 **위 여분까지** 덮는다(`topExtra`).

### 9.6 장비 드롭 빛기둥 (월드)
떨어지는 순간 희귀도 색 세로 빛기둥(폭 18→6, 높이 110~310, 아래 진하게) + 바닥 타원 링 + 반짝 입자 → 등급별 대기 후 곡선 비행으로 **영웅 버튼(BAG_POS)** 에 꽂힘 + 버튼 톡 + NEW. 일반 = 기둥 없음 · 고급 .6초 · 희귀 · 영웅 링 2회 · 전설 회전 후광 + 80ms 섬광 + 150ms 히트스톱 + 이름표(희귀도 밝은 색, Display 15).

### 9.7 마법탄 (매직 미사일) — **새 규격, 최우선 FX 작업**
"핀·막대·총알"처럼 보이면 실패. 구성(아래→위, 전부 구운 텍스처):
1. **꼬리**: 곧은 띠 대신 **점점 작아지는 잔상 구슬 4~5개**(속도 역방향 6~9 월드px 간격, 크기 100→35%, 알파 .8→.1, 원소 메인→에지) + 가산 헤일로 1장. 길이 ≤ 44.
2. **헤드**: 지름 14~18 구체 = 흰 코어(35%) + 원소 메인 링 + 에지색 가는 테(외곽선 대신) + 좌상단 광택 점. 16~24Hz 크기 떨림 ±6%.
3. **반짝**: 4각 별 스파클 1개가 헤드 주위를 0.3초 주기로 공전(탄 수 < 140일 때), 가끔 마력 입자 떨굼.
4. **변형**: P1 금빛(화염 카드면 주황 불꽃 혀가 헤드 뒤로 날림) · P2 청록 냉기(육각 결정 반짝) · 관통 = 길쭉한 마력 창(꼬리 2배, 끝이 뾰족) · 유도 = 도깨비불(꼬리가 휘어짐, 분홍/보라) · 치명 발사 = 헤드 1.3배 + 흰 테. 다중 시전 부채꼴은 탄마다 크기 ±8%·위상 달리해 "벽지" 느낌 제거.
5. **시전**: 지팡이 오브 섬광 + 발밑이 아닌 **오브 앞 룬 마법진**(0.11초마다) — 이미 있음, 유지.
6. **명중**: §9.3 + 원소별 파편(금빛 별 조각 / 청록 얼음 조각).
7. **위 여분**: 탄이 y < 0 으로 나가면 0.15초 페이드(지금은 y < −60에서 뚝 사라짐).
성능: 탄 260발 이상이면 꼬리 구슬 2개·스파클 없음(LOD).

## 10. 화면별 목표

### 10.1 타이틀
풀스크린 키아트: 아래 ⅓ 테마 성벽(금 장식 흉벽) 위 영웅 + 마법사 2명, 가운데 멀리 5테마 층탑(100층 탑) 실루엣, 위 로고. 적 떼가 탑 쪽에서 몰려오는 전경 패럴랙스 3층. 로고는 Impact, "100층 돌파" 리본은 접힌 끝. 시작 = `.k-btn.l` 1개 + "N층부터" 부제, 도감·상점·설정·영웅 = 하단 `.k-btn.round` 아이콘 줄, 협동 = 잠금 배지 작은 아이콘. 진입: 로고 슬램 → 버튼 스태거 → 적 레이어.

### 10.2 전투 HUD
- **무대 = 화면 전체 높이**(✅). DOM HUD는 화면 맨 위, 월드는 아래에 붙고 위 여분(topExtra)은 배경. HUD 기준 캔버스 좌표는 `core.hudY(y)` / `GOLD_POS`·`BAG_POS`·`MANA_POS` getter.
- 좌상: 골드 알약(코인 아이콘이 알약 밖으로 반쯤). 우상: 보석 알약 + 메뉴 `.k-btn.round.neutral`. 영웅 버튼 = 초상 + Lv 배지 + 전투력(중심 = BAG_POS, 좁은 화면에서도 `--u` 기준 고정 크기 → 글자 min px로 틀어지지 않게).
- 중앙: "25층" Impact + 테마 이름 Display 13 + 웨이브 바(`.k-bar`) + 마나 바(8px) + 광폭화 칩(DOM 한 곳만 — 캔버스 알약으로 다시 그리지 않음).
- **오른쪽 스킬 스택**(`#side-r`, 스킬 중심 개편): 이번 도전에서 고른 스킬 6칸이 세로로(원형 원소 구슬 + 쿨타임 고리 + Lv 점 5개, 빈 칸 = 점선 룬 소켓, 융합 스킬 = 두 원소 반반 + 금 테 + 도는 후광) + `n/6` 알약. 좁은 화면 = 영웅 버튼 아래 전장 가장자리에 겹침, 넓은 화면(`#stage.wide`) = 오른쪽 여백의 유리 패널 '마법서'(이름·Lv 표시, `.slim`이면 구슬 2열). 합체 = 두 구슬이 날아와 하나로 + 빈 칸 반짝('슬롯 해제!'는 꽉 찬 슬롯에서 합체했을 때만).
- **왼쪽 열**(`#side-l`): 영웅 카드(초상 + 체력 고리) · 합동 필살 칩 · 켜진 협공 타일 · (넓은 화면) AI 동료 주문. 협공 빛줄기(영웅 초상 ↔ 엮인 구슬)는 평소 숨기고 협공이 켜지거나 터질 때만 가늘게 한 번 흐른다(엮인 구슬은 클래스 색 고리로 숨 쉼).
- 영웅 버튼: 좁은 화면 = 전장 우상단(BAG_POS), 넓은 화면 = 오른쪽 여백 위쪽(마법서 패널 바로 위).
- 보스바는 영웅 버튼 영역을 비운다(§4.5). 토스트는 보스바 아래, 패배 도장이 뜨면 치운다.
- 콤보: 우측 중단, Impact h1 + 단계 리본. 오른쪽 끝 = 스킬 스택 왼쪽 끝(좁은 화면, `hud.setStackLeft`) — 스택 뒤로 숨지 않게. **컷인·클리어·모달·카드 선택 중엔 숨김**.

### 10.3 하단 패널
`.k-panel` 밤 유리. **전투 중 골드 강화 버튼·자동 강화 토글은 없다**(스킬 중심 개편 — 같은 5종은 정비 화면 '마법사 수련', 골드). 하단 패널 = 비상 마법 **운석 · 빙결** + **영웅 궁극기**(클래스 문장, 쿨다운 부채꼴, 준비 시 광택 스윕 · 닿는 곳에 적이 없으면 흐리게, 합동 필살 창이 열리면 금빛 고리) 왼쪽 묶음 + **자동 전투 · 배속 · 자동 진행** 오른쪽 묶음. 비상 마법 = `.k-btn.round` 64px + SVG + 이름 작은 알약.

## 11. 폰트 사용 규칙 (캔버스 포함) — **연결 완료**
- `index.html`: woff2 2종 preload + `css/fonts.css` → `css/kit.css` → `style.css` → `hero.css` 순. 상대 경로라 Capacitor 오프라인 동작.
- `style.css --font` = `var(--font-display)`, `hero.css --hu-font` 동일. `.num`/로고/클리어 제목 = Impact, 설명문 = Body(§5).
- 캔버스: `core.FONT`(Display 우선) · `core.NUM_FONT`(Impact 우선) · `core.BODY_FONT`. `ctx.font`에 **따옴표 포함 패밀리 이름**. 부팅 때 `render.fontsReady()`(= `core.waitFonts`)가 `document.fonts.load` 3종을 시작하고 최대 1.5초 기다리며, 로드되면 `core.onFontsReady` 훅을 부른다 → **글자를 구워 캐시하는 모듈은 반드시 훅에서 캐시를 비운다**. 지금 캔버스 글자는 매 프레임 `fillText`라 캐시 없음.
- 서브셋: ASCII + KS X 1001 2350자 + `public/` 소스의 모든 한글. 2026-09-26 확인: **소스의 한글 음절 전부 포함**(주아·검은고딕 2501, 고운돋움 2536 글리프). 기호(`·×→▲▼▶★☆✦`)와 이모지는 원본에 없어 시스템 글꼴로 대체됨.
- 새 UI 문구에 2350자 밖 글자(예: 똠, 뷁)를 넣으면 □ → 아래를 다시 실행하고 woff2 3개 교체:
```sh
python -m venv .venv-fonts && .venv-fonts/Scripts/pip install fonttools brotli
# 원본 TTF: https://github.com/google/fonts  ofl/jua/Jua-Regular.ttf · ofl/blackhansans/BlackHanSans-Regular.ttf · ofl/gowundodum/GowunDodum-Regular.ttf
```
```python
import pathlib; from fontTools import subset; from fontTools.ttLib import TTFont
PUB = pathlib.Path('public'); OUT = PUB / 'assets/fonts'
ch = {chr(c) for c in range(0x20, 0x7F)} | {chr(c) for c in range(0x3131, 0x3164)} | set('·…×÷±→←↑↓▲▼▶◀★☆♥♡♪✦✕※○●◆◇■□「」『』〈〉《》～°%‰‘’“”')
ch |= {bytes([a, b]).decode('euc_kr') for a in range(0xB0, 0xC9) for b in range(0xA1, 0xFF)}  # 2350자
for f in PUB.rglob('*'):
    if f.suffix in ('.js', '.html', '.css') and 'assets' not in f.parts:
        ch |= {c for c in f.read_text(encoding='utf-8') if 0xAC00 <= ord(c) <= 0xD7A3}
for src, name in [('Jua-Regular.ttf', 'Jua'), ('BlackHanSans-Regular.ttf', 'BlackHanSans'), ('GowunDodum-Regular.ttf', 'GowunDodum')]:
    o = subset.Options(); o.flavor = 'woff2'; o.layout_features = ['*']; o.name_IDs = ['*']; o.hinting = False
    font = TTFont(src); s = subset.Subsetter(o); s.populate(text=''.join(ch)); s.subset(font); font.flavor = 'woff2'; font.save(OUT / f'{name}.woff2')
```
(현재: Jua 184 KB · BlackHanSans 80 KB · GowunDodum 153 KB, 합계 ≈ 417 KB.) 라이선스 SIL OFL 1.1, `OFL-*.txt` 동봉.

### 14.3 공통 규약
- 모든 `draw*`는 **월드 변환(`wt()`) 상태에서 시작하고 끝낼 때 `wt()`(또는 HUD는 `ht()`) + `globalAlpha=1` + `'source-over'`로 되돌린다**. 좌표는 월드 720×1100(성벽 윗면 `WALL_Y=960`), y<0은 위 여분.
- 시간: `T`(애니메이션, 히트스톱 중 멈춤) / `RT`(실시간) / `da`(애니 dt) / `dt`(실제 dt). 움직이는 연출은 `T`·`da`, UI·흔들림은 `RT`·`dt`.
- 텍스처는 `core.bake(key, hw, hh, draw, res?)` 로 굽는다(키는 전역 캐시라 **모듈 접두사** 사용: 유닛 `e|` `h|` `m|`, 월드 `bg|` `wall|`, FX `g|` `rc|` 등 기존 키 유지, 새 키는 `u:` `w:` `f:` `h:` 접두사). 해상도 변경 시 캐시 전체가 비워진다(`setScale`).
- 카메라는 어디서든: `shake(a)`, `flash(a, col)`, `punchZoom(z)`. 파티클·빛은 FX API로(아래).
- HUD 기준 좌표는 `hudY(y)`, 골드/가방/마나 위치는 `GOLD_POS`·`BAG_POS`·`MANA_POS`(y getter). 화면 전체를 덮는 사각형은 `0, -topExtra, WORLD_W, WORLD_H + topExtra`.
- 성능 §12. `shadowBlur` 금지.
