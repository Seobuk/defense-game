- git commit, push, 배포를 하지 않는다. 패키지 설치도 하지 않는다.
- 순수 HTML/CSS/JS만 쓴다. 프레임워크나 빌드 도구는 쓰지 않는다. 외부 리소스는 Google Fonts만 허용한다.

## 게임 소개 (페이지 내용의 근거)
- 장르: 캐주얼 마법 성벽 디펜스 + **로그라이트**. 모바일 세로 화면.
- 핵심 흐름: 성벽 위 **마법사 2명**이 주문(화염구·서리 화살·카드로 얻은 스킬)만으로 몰려오는 몬스터를 막는다. 성벽이 무너지면 도전이 끝나고, **정비 화면**에서 보석으로 영구 강화, 영웅·특성·시작 스킬을 고른 뒤 **1층부터 다시 도전**한다.
- **영웅 5클래스**(기사·궁수·마법사·성직자·암살자)가 맵을 누비며 자동으로 싸운다(탭하면 이동, 궁극기 버튼). 클래스마다 **특성 트리 3갈래 × 6노드**, 마지막 노드는 전투 방식을 바꾸는 궁극 특성.
- **판타지 스킬 카드**(3장 중 1장, 14종, 슬롯 6칸 × Lv5) + **원소 융합 8종** = **히든 조합 22종**(조건 비공개, 발견하면 컷인과 도감 등록).
- 100층, 5테마(슬라임 초원·고블린 동굴·언데드 묘지·화산 용암지대·심연의 마왕성), 10층마다 네임드 보스(킹 슬라임 … 종말의 드래곤).
- 연속 처치 **COMBO**와 광란, 장비 파밍(등급 5단계, 빛기둥 드롭), 방치 보상, 자동 강화.
- **Android APK**(앱이 스스로 업데이트)와 **iPhone 웹앱(PWA)**(홈 화면에 추가, 오프라인, 자동 업데이트) 둘 다 무료. 광고 없음, 서버로 개인정보를 보내지 않음(기록은 기기에 저장, 백업 코드로 옮기기 가능).
- 협동 모드는 준비 중.

## 디자인 방향
게임 아트 방향 "반짝 성채 (Bright Keep)"와 맞춘다. `docs/ART.md`와 `public/css/kit.css`를 읽고 팔레트·폰트·버튼 느낌을 가져온다(수정은 하지 말 것).
- 굵은 잉크 외곽선, 3단 셀 명암, 광택 있는 "젤리 블록" 버튼, 밤하늘 남색 + 금색 포인트, 판타지 룬·마력 입자.
- 폰트: Black Han Sans(제목·숫자), Jua(디스플레이), Gowun Dodum(본문) — Google Fonts로 불러온다.
- 템플릿 같은 느낌 금지(보라→파랑 그라데이션 히어로, 이모지 섹션 제목, 모든 요소 가운데 정렬 금지). **모바일 우선**(대부분 폰으로 방문), 빠르게 로드, 접근성(대비, alt, 포커스), 콘솔 오류 0.

## 페이지 구성
1. **히어로**: 게임 로고(텍스트 로고를 CSS로 멋지게), 한 줄 훅(예: "주문 하나로 100층까지. 무너지면 다시, 더 강하게."), 버튼 두 개:
   - `Android APK 다운로드` → `https://github.com/Seobuk/defense-game/releases/latest/download/defense-game.apk`
   - `iPhone에서 플레이` → `./play/`
   - 버튼 아래에 최신 버전·날짜·용량 표시: `https://api.github.com/repos/Seobuk/defense-game/releases/latest`를 fetch해서 표시. 실패(릴리즈 없음·오프라인·rate limit)하면 조용히 "최신 버전"으로 대체.
2. **플레이 영상/스크린샷 영역**: 폰 목업 프레임 안에 넣을 자리만 만든다. 실제 파일은 나중에 다른 에이전트가 `landing/assets/`에 넣는다. 각 자리에 `data-media="gameplay-video"`, `data-media="shot-1"` … `shot-6` 속성을 달고, 지금은 게임 색감에 맞는 그라데이션 플레이스홀더로 채운다(깨진 이미지 금지).
3. **특징 섹션**: 로그라이트 도전 / 영웅 5클래스 × 특성 트리 / 주문만 쓰는 마법사와 주문서 / 스킬 카드 + 원소 융합 + 히든 조합 22종(??? 카드 연출로 신비감) / 100층·5테마·네임드 보스 / 자동 업데이트.
4. **설치 방법**
   - Android: 다운로드 → 파일 열기 → "출처를 알 수 없는 앱" 허용 → 설치. 이후 업데이트는 앱 안에서 자동.
   - iPhone: Safari로 `./play/` 열기 → 공유 버튼 → "홈 화면에 추가" → 아이콘으로 실행. 3단계 그림(인라인 SVG로 간단히)을 넣는다.
5. **신뢰**: APK 서명 인증서 SHA-256 지문 자리(`data-fingerprint`, 값은 나중에 채움), GitHub 소스 링크 `https://github.com/Seobuk/defense-game`, MIT 라이선스.
6. **FAQ**: 무료인가요? / 광고 있나요? / 데이터는 어디 저장되나요?(기기 저장, 백업 코드) / iPhone도 되나요? / 협동 모드는?
